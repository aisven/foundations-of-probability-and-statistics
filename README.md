# foundations-of-probability-and-statistics

Introduction to certain concepts with code for educational purposes.

## Getting Started

```
make sync
make format-and-lint-code
make test
```

## Probability Distribution of Cars

Under `foundations_of_probability_and_statistics/cars` a non-trivial toy
probability distribution of cars is modeled and parameterized.

## Notebooks

Some notebooks cen be found in the directory `notebooks`.
Each notebook aims to highlight a particular topic from probability and statistics.
